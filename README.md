# Math Meteor Shooter (數學隕石射擊)

這是一款結合 **九九乘法表** 與 **射擊遊戲** 的教育網頁遊戲。玩家需要操控飛機，計算螢幕上顯示的數學題目（例如 `3 × 7 = ?`），並射擊帶有正確答案數字的隕石。

## 🎮 遊戲特色

*   **寓教於樂**：在緊張刺激的射擊遊戲中練習數學乘法。
*   **多種難度**：提供 **初級**、**中級**、**高級** 三種難度，適合不同程度的玩家。
*   **排行榜系統**：與全球玩家一較高下，爭取榜首榮耀。
*   **錯題分析**：遊戲結束後會顯示答錯的題目，幫助複習。
*   **成績單下載**：可生成並下載精美的成績單圖片分享給朋友。
*   **跨平台支援**：支援電腦鍵盤操作與手機觸控虛擬搖桿。

## 🕹️ 如何操作 (Controls)

### 電腦版 (PC)
*   **移動**：使用鍵盤方向鍵 [`←` `↑` `↓` `→`] 或 [`W` `A` `S` `D`] 控制飛機移動。
*   **射擊**：按 [`空白鍵 (Space)`] 發射子彈。
*   **暫停**：按 [`Esc`] 或 [`P`] 暫停遊戲。

### 手機版 (Mobile)
*   **移動**：使用左側的 **虛擬搖桿** 拖曳控制飛機。
*   **射擊**：點擊右側的 **🔥 發射按鈕**。

## ⚙️ 遊戲機制與設定

### 1. 難度選擇 (Difficulty)
遊戲開始前可選擇三種難度，影響生命值與隕石下墜速度：
*   **🌟 初級 (Easy)**：5 條命，速度最慢。特色：隕石降落到一半時，正確答案會發出綠光提示。
*   **⚡ 中級 (Medium)**：3 條命，標準速度。
*   **🔥 高級 (Hard)**：2 條命，速度最快，挑戰反應極限。

### 2. 規則 (Rules)
*   **得分**：射中「正確答案」的隕石，獲得分數（分數隨關卡提升）。
*   **扣分**：射中「錯誤答案」的隕石，倒扣 10 分。
*   **扣血 (失去生命)**：
    1.  飛機被隕石撞擊。
    2.  「正確答案」的隕石掉落到畫面最底部（漏接）。
    *   *注意：射錯隕石不會扣血，只會扣分。*

### 3. 關卡進度 (Stages)
*   遊戲共有 **20 個關卡**。
*   每關需要擊落指定數量的正確隕石才能晉級。
*   隨著關卡提升，隕石下墜速度會越來越快，題目範圍也會逐漸擴大（從簡單的 1-5 乘法到 1-12 乘法）。

### 4. 遊戲自訂
*   **每關隕石數**：可設定每一關需要擊落的隕石數量 (5 / 10 / 15 / 20)。
*   **音效開關**：遊戲中可透過右上角按鈕開關音效。

## 🏆 排行榜 (Leaderboard)

遊戲內建即時排行榜系統：
*   **排名依據**：優先比較 **關卡數 (Stage)**，其次比較 **分數 (Score)**。
*   **展示方式**：列出前 10 名頂尖玩家。
*   **個人排名**：如果您的成績未進入前 10 名，會在列表底部單獨顯示您的名次。
*   **資料儲存**：使用 Firebase Firestore 雲端儲存，確保數據即時且持久。

## 🛠️ 技術棧 (Tech Stack)

*   **Frontend**: HTML5, CSS3 (Animations), Vanilla JavaScript
*   **Backend**: Firebase (Firestore) - 用於儲存排行榜數據
*   **Libraries**:
    *   `html2canvas`: 用於將結算畫面生成為圖片下載。
    *   `FileSaver.js`: 處理檔案下載功能。
